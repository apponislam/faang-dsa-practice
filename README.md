# FAANG DSA Practice

A collection of Data Structures and Algorithms problems commonly asked in FAANG interviews, implemented in JavaScript.

## Problems List

1. **Reverse Words** - Reverse words in a string
2. **Find Pairs Sum** - Find pairs of elements that sum to a target
3. **Array Palindrome** - Check if an array is a palindrome
4. **Rotate Matrix** - Rotate a 2D matrix
5. **Remove Duplicates** - Remove duplicates from an array
6. **Longest Increasing Subsequence** - Find the longest increasing subsequence
7. **Count Vowels** - Count vowels in a string
8. **Find Majority Element** - Find the majority element in an array
9. **Rotate String by K** - Rotate a string by K positions
10. **Find Missing Consecutive** - Find missing numbers in a consecutive sequence
11. **Rotate Array by K** - Rotate an array by K positions
12. **Find Missing Number** - Find the missing number in an array
13. **Merge Sorted Arrays** - Merge two sorted arrays
14. **Longest Substring No Repeat** - Find the longest substring without repeating characters
15. **Check Arrays Equal** - Check if two arrays are equal

## Usage

Each problem is in its own JavaScript file. You can run them using Node.js:

```bash
node 01-reverse-words.js
```
